Ferro Fabs Web V2.2 – Clean PC Build

1. Extract this ZIP to a normal Windows folder (for example Desktop\\FerroFabs).
2. Double-click index.html.
3. Click “Choose shelf photo” and select a JPG/PNG/WebP.
4. The photo should immediately appear. Drag the four large green corner circles.
5. Choose 1–4 doors, select a finish, then Apply finish to doors.
6. Export JPG.

No Live Server, Node.js, Python, or installation is required.

This build intentionally uses ordinary local assets instead of giant embedded data URLs, to avoid the failure mode in earlier offline builds.
